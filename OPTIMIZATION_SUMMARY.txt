WHAT WAS WRONG (ROOT CAUSES)
============================

1. GRADIENT EXPLOSION (Loss: 86 billion)
   Cause: Metadata features with 10-order scale difference
   Fix: StandardScaler normalization

2. MODEL COLLAPSED (All predictions = Class 5)
   Cause: Numerical instability from unnormalized features
   Fix: Batch normalization + Layer normalization

3. CLUTTER = FALLBACK CLASS
   Cause: Clutter was all zeros (easy default)
   Fix: Realistic clutter signal with noise

4. NO GRADIENT STABILITY
   Cause: No gradient clipping when features unstable
   Fix: Added torch.nn.utils.clip_grad_norm_

5. INSUFFICIENT DATA
   Cause: Only 5 samples/class × 2 epochs
   Fix: 200 samples/class × 50 epochs
